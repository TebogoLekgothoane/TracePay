# TracePay website

Marketing website for TracePay, a South African financial intelligence startup.
Built with Next.js (App Router), TypeScript (strict), Tailwind CSS v4, Framer Motion and Lucide React.

This is a marketing site, not a live financial service. It does not connect to any bank, database or sign-up system.
All transactions and figures shown are illustrative sample data and are labelled that way on the page.

## Run it locally

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

Before deploying, run the checks:

```bash
npm run typecheck
npm run lint
npm run build
```

## Pages

| Route | Content |
| --- | --- |
| `/` | Hero, problem, how it works, what we detect, interactive demo, security, about, final call to action |
| `/how-it-works` | Process, problem examples, interactive demo |
| `/what-we-detect` | The six detection categories and the interactive demo |
| `/security` | Principles, what TracePay can and can't determine |
| `/about` | Mission and purpose |
| `/privacy`, `/terms` | Clearly marked placeholders (not indexed) |

`/sitemap.xml`, `/robots.txt`, the favicon (`app/icon.svg`) and the social sharing image (`app/opengraph-image.tsx`) are generated by Next.js.

## Project structure

```
app/                     routes, layout, global styles, sitemap, robots
components/              reusable components (header, footer, hero, showcase, sections)
lib/content.ts           all copy and sample data in one place
lib/utils.ts             small helpers
```

To change wording or sample data, edit `lib/content.ts`. Design tokens (colours, fonts) are at the top of `app/globals.css`.

## Before you launch

- Replace the placeholder logo mark in `components/logo.tsx` and `app/icon.svg` with the approved TracePay logo.
- Replace the placeholder pages at `app/privacy/page.tsx` and `app/terms/page.tsx` with approved legal text.
- Confirm `hello@tracepay.co.za` is an active address (set in `lib/content.ts`).
- Check every privacy and security statement against how the product actually works.
- Replace the illustrative app screens in `components/app-screens.tsx` with real screenshots if you prefer (remove personal details first).
- Add analytics only if needed, with the right privacy disclosure.

## Deploy to Vercel and connect tracepay.co.za

1. Push this folder to a new GitHub repository.
2. In Vercel, choose **Add New > Project**, import the repository and deploy it. The Next.js defaults need no changes.
3. Open the project's **Settings > Domains** and add `tracepay.co.za` (and optionally `www.tracepay.co.za`).
4. Add the DNS records Vercel shows you at your domain provider, then wait for verification and HTTPS.

Do not delete your existing email DNS records (MX, SPF, DKIM, DMARC) when adding the website records.

No environment variables are required.
